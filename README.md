# Gyirong FloodGuard
# 吉隆防洪卫士

### Interactive Flood Warning and Evacuation Guidance Prototype
### 交互式洪水预警与疏散引导原型

Gyirong FloodGuard is an interactive prototype designed to demonstrate a community-oriented flood early-warning and evacuation guidance system.
Gyirong FloodGuard 是一个交互式原型,用于演示一套面向社区的洪水预警与疏散引导系统。

## Features
## 功能特性

- **Multi-level Alert System:** Demonstrates Blue, Yellow, Red, and Cancelled warning states.
- **多级预警系统:** 演示蓝色、黄色、红色和解除预警四种状态。

- **Scenario Simulation:** Allows operators to select different scenarios and advance the simulation step by step.
- **情景模拟:** 允许操作者选择不同的情景,并逐步推进模拟进程。

- **Evacuation Guidance:** Displays two possible evacuation destinations and their illustrative routes.
- **疏散引导:** 展示两个可能的疏散目的地及其示意路线。

- **Resident Mobile Interface:** Provides a simplified phone interface showing the current alert, evacuation options, and recommended actions.
- **居民手机界面:** 提供一个简化的手机界面,显示当前预警、疏散选项和建议行动。

- **Operator Control Panel:** Allows users to control and reset the demonstration.
- **操作员控制面板:** 允许用户控制和重置演示。

## How to Use
## 使用方法

1. Open the published webpage.
1. 打开发布的网页。

2. Use the left-side Operator Control Panel to select a scenario.
2. 使用左侧的操作员控制面板选择一个情景。

3. Click **Next Update** to advance the simulation.
3. 点击 **Next Update(下一步更新)** 推进模拟。

4. Observe how the alert level and recommended actions change.
4. 观察预警等级和建议行动如何变化。

5. View the right-side Resident Mobile Interface to see the information presented to residents.
5. 查看右侧的居民手机界面,了解呈现给居民的信息。

## Technical Information
## 技术信息

- Built with HTML, CSS, and JavaScript.
- 使用 HTML、CSS 和 JavaScript 构建。

- Runs directly in a web browser.
- 直接在网页浏览器中运行。

- No external API or backend connection required.
- 无需外部 API 或后端连接。

- All simulation data is locally embedded in the webpage.
- 所有模拟数据均本地内嵌于网页中。

## Important Notice
## 重要声明

This is an academic demonstration prototype. All readings, locations, evacuation routes, and scenario outcomes are simulated. The displayed destinations and travel times are illustrative and have not been verified for real-world emergency use.
这是一个学术演示原型。所有读数、位置、疏散路线和情景结果均为模拟。所显示的目的地和行程时间仅作示意,未经真实应急场景验证。
